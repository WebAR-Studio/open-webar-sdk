# WebAR SDK

`webar-sdk` is a convenient package entry for Open WebAR SDK.
It provides the same runtime and API surface as `@web-ar-studio/webar-engine-sdk`.

Keywords: WebAR SDK, image tracking, face tracking, works on iOS Safari, MindAR alternative.

## Install

```bash
npm install webar-sdk
```

## Use

```js
const WebAREngine = require('webar-sdk');
```

## Notes

- API-compatible with `@web-ar-studio/webar-engine-sdk`
- Good fit if your team prefers shorter package names in examples

## Recommended starter

```bash
npx create-webar-app my-ar --image
```
